# Phishing Awareness Guide

## What is phishing?
Phishing is a social-engineering attack where an attacker pretends to be a trusted party (bank, employer, courier) to steal credentials, money or data.

## Common types
| Type | Description |
|------|-------------|
| Email phishing | Mass emails with fake links or attachments |
| Spear phishing | Targeted at a specific person or organisation |
| Smishing | Phishing via SMS |
| Vishing | Phishing via phone calls |
| Business Email Compromise | Impersonating executives to request payments |

## Red flags
1. Urgent or threatening language ("Your account will be closed in 24 hours")
2. Sender address that does not match the organisation's real domain
3. Generic greetings such as "Dear Customer"
4. Links whose real destination differs from the displayed text (hover to check)
5. Unexpected attachments or requests for passwords/OTPs
6. Spelling and grammar errors

## What to do if you receive a suspicious message
1. Do **not** click links or open attachments
2. Verify with the organisation using a known, trusted contact method
3. Report it to your IT/security team
4. Delete the message

## If you already clicked
1. Disconnect from the network
2. Change affected passwords from a clean device
3. Report to IT/security immediately
4. Monitor accounts for suspicious activity
