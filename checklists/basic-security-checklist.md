# Basic Cybersecurity Checklist

## Accounts and Passwords
- [ ] Use a unique password of 12+ characters for every account
- [ ] Use a password manager
- [ ] Enable multi-factor authentication (MFA) on email, banking and social media
- [ ] Never share passwords by email, SMS or chat

## Devices
- [ ] Enable automatic operating-system and app updates
- [ ] Install reputable anti-malware software
- [ ] Turn on a screen lock (PIN, password or biometrics)
- [ ] Encrypt laptops and phones (BitLocker, FileVault, device encryption)

## Network
- [ ] Change the default router admin password
- [ ] Use WPA2/WPA3 on Wi-Fi
- [ ] Avoid public Wi-Fi for sensitive activity, or use a VPN
- [ ] Keep the firewall enabled

## Data
- [ ] Back up important files (3-2-1 rule: 3 copies, 2 media types, 1 offsite)
- [ ] Test restoring a backup at least twice a year
- [ ] Delete data you no longer need

## Email and Browsing
- [ ] Check sender addresses and links before clicking
- [ ] Do not open unexpected attachments
- [ ] Only download software from official sources
