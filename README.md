# Cybersecurity Awareness Pack

A small collection of practical cybersecurity resources created as a junior cybersecurity analyst mini-project.

## Purpose
To help individuals and small teams adopt basic security habits, recognise phishing and report incidents consistently.

## Repository structure

    cybersecurity-awareness-pack/
    ├── README.md
    ├── checklists/
    │   └── basic-security-checklist.md
    ├── guides/
    │   └── phishing-awareness.md
    └── templates/
        └── incident-report-template.md

## Contents
| File | Description |
|------|-------------|
| [Basic Security Checklist](checklists/basic-security-checklist.md) | Tick-box checklist for accounts, devices, network and data |
| [Phishing Awareness Guide](guides/phishing-awareness.md) | Types of phishing, red flags and response steps |
| [Incident Report Template](templates/incident-report-template.md) | Standard form for recording security incidents |

## How to use
Copy or download the files and adapt them to your organisation. Review the checklist regularly.
